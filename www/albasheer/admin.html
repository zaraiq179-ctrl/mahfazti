ربط الحساب (مرة وحدة)

اللوحة تحفظ تعديلاتك مباشرة بمستودع الموقع على GitHub. تحتاج «رمز وصول» من GitHub وتختار كلمة سر للوحة.

  1. افتح صفحة إنشاء رمز جديد.
  2. الاسم: albasheer-admin — المدة: سنة.
  3. Repository access ← Only select repositories ← اختار مستودع الموقع.
  4. Permissions ← Contents ← Read and write.
  5. Generate token وانسخه هنا.

الأطباء

عدّل الصورة والمعلومات، رتّب، أخفِ، أو أضف طبيب جديد.

صور المرضى

تظهر بقسم «لحظات من رحلات مرضانا». رتّبها بالأسهم، والصور الجديدة تتصغر تلقائياً.

المستشفيات

غيّر صورة كل مستشفى (صورة أفقية للمبنى أو الاستقبال)، رتّبها، أو أخفِ مستشفى.

قصص المرضى

اكتب كلام المريض مثل ما قاله، وبعد موافقته على النشر. القسم يظهر بالموقع من تضيف أول قصة.

النصوص والأسعار

عنوان الصفحة الرئيسية وسعر الاستشارة، بالأربع لغات.
